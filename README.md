# FIN 325 Applied Finance Lab

A professional GitHub Pages/MkDocs shell for **FIN 325: Finance for Managers**.

This repository is designed as a reusable course platform, not a simple file dump. It supports a polished student-facing experience built around the course framework:

> **Build → Analyze → Decide**

## What this shell includes

- MkDocs Material configuration
- GitHub Actions deployment workflow
- Professional navigation structure
- Homepage shell
- Start Here section
- Course roadmap
- Module placeholders
- Finance Lab placeholders
- Investment memo placeholders
- Capstone project structure
- Student resources structure
- Custom CSS and JavaScript hooks
- Reusable Markdown templates

## Quick start

1. Upload these files to your `fin-325` GitHub repository.
2. In GitHub, go to **Settings → Pages**.
3. Set the source to **GitHub Actions**.
4. Push to the `main` branch.
5. GitHub Actions will build and deploy the site.

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open the local server link provided in the terminal.

## Design philosophy

This site is designed to make FIN 325 feel like a professional finance analyst training environment. The goal is not just to organize assignments. The goal is to create a coherent learning system where students build technical skills, analyze financial decisions, and defend recommendations.
