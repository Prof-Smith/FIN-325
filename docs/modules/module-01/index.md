## Essential Question

How do financial managers create value, and how can we determine whether a company is financially healthy?

## Learning Outcomes

By the end of this module, you should be able to:

- **LO1:** Describe the role of managerial finance and the financial market environment.
- **LO2:** Evaluate a firm's financial performance utilizing key financial measures and future financial plans based on these measures.

## Module Structure

### Prepare

- Read assigned textbook chapters.
- Participate in class discussion on financial decision-making, markets, governance, and firm performance.

### Practice

- Complete assigned MyFinanceLab practice.

### Build

- Complete Lab 1: Financial Diagnosis.

### Analyze

- Interpret liquidity, profitability, efficiency, leverage, and DuPont results.

### Decide

- Make a recommendation regarding whether the company appears financially healthy.
