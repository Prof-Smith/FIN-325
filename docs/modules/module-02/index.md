## Welcome to Module 2

Module 2 turns financial information into interpretation. Students learn that ratios are not formulas to memorize, but tools for diagnosing liquidity, efficiency, debt, profitability, and overall financial performance.

---

## Essential Question

> **How can financial statements and ratios help analysts diagnose firm performance and financial health?**

---

## Learning Outcomes

By the end of this module, you should be able to:

### Primary Outcome

#### LO2

**Evaluate a firm's financial performance utilizing key financial measures and future financial plans based on these measures.**

### Integrated Prior Outcome

This module also draws on earlier or related course outcomes so students can connect individual finance tools into broader financial judgment.

- **LO1:** Financial analysis is connected back to the role of managers, creditors, investors, and financial markets.
