## How the Course Works

<div class="decision-box">
<strong>Every lab produces evidence. Every memo converts evidence into a professional recommendation. The capstone synthesizes those recommendations into a final investment committee package.</strong>
</div>

### Weekly Rhythm

1. Read the module page.
2. Use the lab interactive tools.
3. Review the worked example.
4. Complete the Excel model or workbook.
5. Write the memo when assigned.
6. Save your best work for the capstone.
