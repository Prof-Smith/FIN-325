# Technology Guide

## Required tools

- Microsoft Excel
- Canvas
- MyFinanceLab
- A reliable web browser

## Recommended habits

- Save all work with clear file names.
- Keep a copy of every submitted spreadsheet.
- Use formulas instead of manual calculations where possible.
- Separate inputs, calculations, and outputs in Excel.

## File naming convention

Use this format when submitting work:

```text
LastName_FirstName_FIN325_Lab01.xlsx
LastName_FirstName_FIN325_Memo01.docx
```
