## Purpose

This short script can be used for a welcome video, an in-class introduction, or a recorded walkthrough of the course site.

## Two-Minute Script

Welcome to FIN 325 Applied Finance Lab. This course is built around a professional finance workflow: **Build, Analyze, Decide**.

Each module introduces a finance concept. Each lab helps you build financial evidence. Each investment memo asks you to convert that evidence into a professional recommendation. The capstone brings everything together into a final investment committee package.

The course is not designed around memorizing formulas in isolation. It is designed to help you think like a financial analyst. That means you will build models, interpret results, explain assumptions, identify limitations, and make decisions under uncertainty.

The basic workflow is simple. Start with the module page. Complete the related lab. Review the worked example. Update your workbook. Write the memo when assigned. Save your strongest evidence for the capstone.

By the end of the course, you should have more than completed assignments. You should have a professional finance artifact that demonstrates your ability to analyze a company, value a stock, evaluate risk, estimate cost of capital, assess investment discipline, and make a responsible recommendation.

The goal is not just to calculate. The goal is to use finance to make better decisions.
