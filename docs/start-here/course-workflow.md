# Course Workflow

Each module follows the same professional workflow.

## 1. Prepare

Read the assigned material and participate in class activities.

## 2. Practice

Use MyFinanceLab or other assigned practice tools to reinforce technical mechanics.

## 3. Build

Create a financial model or analytical artifact.

## 4. Analyze

Interpret the model output and explain what the numbers mean.

## 5. Decide

Make a recommendation and defend it with evidence.

```text
Prepare → Practice → Build → Analyze → Decide
```
